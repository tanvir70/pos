# Task 2 Brief: Database Schema & Flyway Migration (The Bulletproof Core)

## Context & Objectives
You are the implementer for Task 2.
Your goal is to implement Flyway migrations `V1__init_syngenta_schema.sql` and `V2__seed_syngenta_data.sql`, and write an integration test `FlywayMigrationTest.java` that validates schema creation, table constraints, foreign keys, and seed data integrity.

## Strict Rules
- Ponytail engineering: Minimal, clean, robust, zero bloat.
- Zero assumptions: If any business or technical judgment is made, add `// BUSINESS DECISION:` or `-- BUSINESS DECISION:` and record in `DECISIONS_LOG.md`.
- No subagents contract: Do NOT invoke any subagents. You do all work directly.
- Compatibility: Schema must run cleanly on both H2 (dev/file mode) and PostgreSQL (production). Use standard ANSI SQL `BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY` or H2/Postgres dual-compatible syntax.
- Number types: Quantities MUST be `NUMERIC(12, 3)`. Currency amounts MUST be `NUMERIC(12, 2)`.

## Deliverables

### 1. `backend/src/main/resources/db/migration/V1__init_syngenta_schema.sql`
Create the 10 tables:
1. `product`:
   - `id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY`
   - `product_code VARCHAR(50) NOT NULL UNIQUE`
   - `name_en VARCHAR(255) NOT NULL`
   - `name_bn VARCHAR(255) NOT NULL`
   - `company_name VARCHAR(150) DEFAULT 'Syngenta'`
   - `category VARCHAR(100) NOT NULL`
   - `base_unit VARCHAR(30) NOT NULL`
   - `carton_multiplier NUMERIC(10, 3) DEFAULT 1.0`
   - `default_barcode VARCHAR(100)`
   - `standard_retail_price NUMERIC(12, 2) NOT NULL`
   - `standard_wholesale_price NUMERIC(12, 2) NOT NULL`
   - `min_stock_alert INT DEFAULT 5`
   - `image_path VARCHAR(500)`
   - `created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP`

2. `inventory_lot`:
   - `id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY`
   - `product_id BIGINT NOT NULL REFERENCES product(id) ON DELETE CASCADE`
   - `lot_number VARCHAR(50) NOT NULL`
   - `entry_date DATE NOT NULL`
   - `expiry_date DATE NOT NULL`
   - `purchase_cost NUMERIC(12, 2) NOT NULL`
   - `lot_retail_price NUMERIC(12, 2) NOT NULL`
   - `lot_wholesale_price NUMERIC(12, 2) NOT NULL`
   - `barcode VARCHAR(100) NOT NULL UNIQUE`
   - `supplier_name VARCHAR(150)`
   - `challan_no VARCHAR(100)`
   - `created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP`

3. `stock_inventory`:
   - `id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY`
   - `lot_id BIGINT NOT NULL REFERENCES inventory_lot(id) ON DELETE CASCADE`
   - `location VARCHAR(20) NOT NULL` (`DOKAN` or `GODOWN`)
   - `quantity NUMERIC(12, 3) NOT NULL DEFAULT 0`
   - `CONSTRAINT uq_lot_location UNIQUE (lot_id, location)`

4. `godown_movement`:
   - `id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY`
   - `lot_id BIGINT NOT NULL REFERENCES inventory_lot(id)`
   - `movement_type VARCHAR(50) NOT NULL` (`PURCHASE_ENTRY`, `TRANSFER_TO_DOKAN`, `DIRECT_WHOLESALE_DISPATCH`, `DAMAGE_EXIT`, `RETURN_ENTRY`)
   - `quantity NUMERIC(12, 3) NOT NULL`
   - `movement_date TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP`
   - `reference_no VARCHAR(100)`
   - `remarks TEXT`

5. `customer`:
   - `id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY`
   - `name VARCHAR(200) NOT NULL` (Proprietor Name)
   - `father_name VARCHAR(150)`
   - `business_name VARCHAR(200)`
   - `phone VARCHAR(50) NOT NULL`
   - `whatsapp_number VARCHAR(50)`
   - `email VARCHAR(100)`
   - `village_address VARCHAR(255)`
   - `customer_type VARCHAR(30) NOT NULL` (`WHOLESALE` or `RETAIL`)
   - `credit_limit NUMERIC(12, 2) DEFAULT 0`
   - `current_due NUMERIC(12, 2) NOT NULL DEFAULT 0`
   - `mfs_type VARCHAR(30)`
   - `mfs_number VARCHAR(50)`
   - `bank_name VARCHAR(100)`
   - `bank_branch VARCHAR(100)`
   - `bank_account_no VARCHAR(100)`
   - `created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP`

6. `customer_ledger`:
   - `id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY`
   - `customer_id BIGINT NOT NULL REFERENCES customer(id) ON DELETE CASCADE`
   - `transaction_date TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP`
   - `transaction_type VARCHAR(50) NOT NULL` (`INVOICE_BILL`, `CASH_PAYMENT`, `RETURN_CREDIT`)
   - `debit NUMERIC(12, 2) DEFAULT 0`
   - `credit NUMERIC(12, 2) DEFAULT 0`
   - `balance_after NUMERIC(12, 2) NOT NULL`
   - `money_receipt_no VARCHAR(50)`
   - `sale_id BIGINT`
   - `notes TEXT`

7. `sale`:
   - `id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY`
   - `invoice_no VARCHAR(50) NOT NULL UNIQUE`
   - `sale_date TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP`
   - `customer_id BIGINT REFERENCES customer(id)`
   - `sale_mode VARCHAR(20) NOT NULL` (`RETAIL` or `WHOLESALE`)
   - `subtotal NUMERIC(12, 2) NOT NULL`
   - `discount NUMERIC(12, 2) DEFAULT 0`
   - `round_off NUMERIC(12, 2) DEFAULT 0`
   - `total_amount NUMERIC(12, 2) NOT NULL`
   - `payment_method VARCHAR(30) NOT NULL DEFAULT 'CASH'`
   - `cash_paid NUMERIC(12, 2) DEFAULT 0`
   - `digital_paid NUMERIC(12, 2) DEFAULT 0`
   - `digital_medium VARCHAR(30)`
   - `digital_trx_id VARCHAR(100)`
   - `due_amount NUMERIC(12, 2) DEFAULT 0`
   - `cashier_name VARCHAR(100)`

8. `sale_item`:
   - `id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY`
   - `sale_id BIGINT NOT NULL REFERENCES sale(id) ON DELETE CASCADE`
   - `lot_id BIGINT NOT NULL REFERENCES inventory_lot(id)`
   - `total_quantity NUMERIC(12, 3) NOT NULL`
   - `dokan_quantity NUMERIC(12, 3) NOT NULL DEFAULT 0`
   - `godown_quantity NUMERIC(12, 3) NOT NULL DEFAULT 0`
   - `unit_price NUMERIC(12, 2) NOT NULL`
   - `unit_cost NUMERIC(12, 2) NOT NULL`
   - `subtotal NUMERIC(12, 2) NOT NULL`

9. `sale_return`:
   - `id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY`
   - `return_no VARCHAR(50) NOT NULL UNIQUE`
   - `original_sale_id BIGINT REFERENCES sale(id)` (Nullable for direct returns)
   - `customer_id BIGINT REFERENCES customer(id)`
   - `return_date TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP`
   - `total_refund_amount NUMERIC(12, 2) NOT NULL`
   - `refund_type VARCHAR(30) NOT NULL` (`CASH_REFUND` or `DUE_ADJUSTMENT`)
   - `reason TEXT`

10. `sale_return_item`:
    - `id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY`
    - `sale_return_id BIGINT NOT NULL REFERENCES sale_return(id) ON DELETE CASCADE`
    - `lot_id BIGINT NOT NULL REFERENCES inventory_lot(id)`
    - `quantity NUMERIC(12, 3) NOT NULL`
    - `refund_price NUMERIC(12, 2) NOT NULL`
    - `is_damaged BOOLEAN DEFAULT FALSE`
    - `restock_location VARCHAR(20) NOT NULL` (`DOKAN` or `GODOWN`)
